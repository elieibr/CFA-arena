# CharterPath 🏆

A gamified, multi-user platform for CFA Level 1 exam preparation with real-time leaderboards, ELO ratings, and competitive leagues.

## Features

### 🎮 Gamification
- **Points System**: Earn points for every correct answer (base 100pts × difficulty multiplier + time bonus)
- **ELO Rating**: Dynamic rating system that adapts to your performance
- **Leagues**: Bronze → Silver → Gold → Diamond → Master (based on ELO)
- **Real-time Leaderboards**: Global, per topic, and per league

### 📚 Learning Features
- **AI-Powered Questions**: Questions generated by Anthropic Claude
- **Spaced Repetition**: Intelligent review system for maximum retention
- **Exam Simulations**: Full-length practice exams with detailed analytics
- **Progress Tracking**: Comprehensive stats across all 10 CFA topics

### 👥 Social Features
- **Public Profiles**: Shareable profile pages with rankings
- **Competitive Rankings**: See how you stack up against other candidates
- **Social Sharing**: Share your achievements on LinkedIn/Instagram

## Tech Stack

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Backend**: Supabase (PostgreSQL + Auth + Real-time)
- **AI**: Anthropic Claude API
- **Deployment**: Vercel (recommended)

## Getting Started

### 1. Supabase Setup

1. Create a new project at [supabase.com](https://supabase.com)
2. Run the schema SQL:
   ```bash
   # In Supabase SQL Editor, paste the contents of supabase-schema.sql
   ```
3. Enable Google OAuth (optional):
   - Go to Authentication → Providers
   - Enable Google provider
   - Add your OAuth credentials

### 2. Local Development

1. Clone and install:
   ```bash
   npm install
   ```

2. Copy environment variables:
   ```bash
   cp .env.local.example .env.local
   ```

3. Fill in your Supabase credentials in `.env.local`

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000)

## Database Schema

### Key Tables

- **profiles**: User profiles with ELO, points, league
- **topics**: 10 CFA Level 1 topics
- **user_topic_progress**: Per-topic progress tracking
- **question_history**: All answered questions
- **exam_simulations**: Full exam results
- **spaced_repetition_cards**: Review system
- **leaderboard_global**: Global rankings (materialized view)
- **leaderboard_by_topic**: Per-topic rankings (materialized view)

### Points Calculation

```
base_points = 100 × topic_difficulty_multiplier
time_bonus = up to 50% for fast answers
total_points = base_points + time_bonus
```

### ELO System

- Starting ELO: 1200
- K-factor: 32
- League thresholds:
  - Bronze: 0-1199
  - Silver: 1200-1399
  - Gold: 1400-1599
  - Diamond: 1600-1999
  - Master: 2000+

## Deployment

### Vercel (Recommended)

1. Push your code to GitHub
2. Import to Vercel
3. Add environment variables
4. Deploy!

### Environment Variables for Production

Make sure to set these in your Vercel project:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `NEXT_PUBLIC_APP_URL`
